# FRÄSKERN

Digitaler B2B-Shop für Zerspanungswerkzeuge.

## Status

Erste Frontend-Basis mit React + Vite. Die Architektur ist bewusst so aufgebaut, dass Produktdaten zunächst lokal gemockt und später über Shopify angebunden werden können.

## Brand

Die verbindliche Mastermarke ist **FRÄSKERN — CUTTING TOOLS** in Blau/Stahl. Änderungen am Logo erfolgen nur nach ausdrücklicher Freigabe.

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
